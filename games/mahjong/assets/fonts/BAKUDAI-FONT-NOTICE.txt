Bakudai Brush Font / 莫大毛筆字體

Source: https://github.com/max32002/bakudaifont
Upstream version used for this subset: 1.48 Regular

Bakudai is derived from Aoyagi Kouzan's Kouzan Brush Font Gyousho. This
project embeds one WOFF2 subset, `bakudai-mahjong.woff2`, for all Mahjong UI
labels, 3D canvas text, result-paper yaku names, and draw-result reasons. The
source-of-truth glyph list is `mahjong-brush-text.txt`; rebuild the subset with
`bash build-bakudai-subset.sh /path/to/Bakudai-Regular.woff2` after changing
that list. The build script requires FontTools with WOFF2 support
(`pip install 'fonttools[woff]'`).
