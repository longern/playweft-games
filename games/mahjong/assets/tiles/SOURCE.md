# Riichi tile face artwork

The artwork in `riichi-faces.webp` is derived from the Regular PNG exports in
[`FluffyStuff/riichi-mahjong-tiles`](https://github.com/FluffyStuff/riichi-mahjong-tiles).

The upstream work is dedicated to the public domain under CC0 1.0. See the
upstream repository and <https://creativecommons.org/publicdomain/zero/1.0/>.

Atlas order: Man 1–9, Pin 1–9, Sou 1–9, Ton, Nan, Shaa, Pei, Haku, Hatsu,
Chun, red Man 5, red Pin 5, red Sou 5. The atlas uses 256 × 352 cells in an
8-column, 5-row 2048 × 1760 image. Each source image is rendered at 240 × 320
inside its cell with transparent padding.
